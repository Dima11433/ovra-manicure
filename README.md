# OVRA — Авторский маникюр & Кутюрный трикотаж

Высококлассный интерактивный лендинг для лейбла авторского маникюра и кутюрного трикотажа OVRA.

## Особенности проекта
- **3 контрастных фона по секциям**:
  - **Секция 1 (Главный экран)**: Белый фарфор (`#FFFFFF`) с акцентом на силуэт модели, кутюрный маникюр и кустовые розы.
  - **Секция 2 (Коллаж)**: Глубокий красный как кровь (`#3D0005` → `#8A0303`) с контурной типографикой «МАНИКЮР».
  - **Секция 3 (Галерея образов)**: Черный обсидиан (`#09070B` → `#050406`) с цикличным показом коллекций ногтевого дизайна.
- **Интерактивные 3D-эффекты**:
  - Парящие в реальном времени 3D-лепестки роз на WebGL с реакцией на движение мыши и скролл.
  - Эффект 3D-наклона карточек при наведении (`perspective(800px)`).
- **Плавная анимация**:
  - Анимированная раскладка букв с трафаретными прорезями (Cyrillic Stencil CSS masks).
  - Эффект реечного проявления изображений (strip reveal).
  - Плавный скролл с инерцией.
- **Чистый дизайн**:
  - Никаких внешних библиотек и фреймворков (чистый HTML5, CSS3, ES6 JavaScript, WebGL).
  - Адаптивная верстка (десктоп 1440×956 и мобильные устройства).

## Запуск локально
Открыть `index.html` в любом современном браузере или запустить локальный сервер:
```bash
python -m http.server 3000
```
Затем открыть в браузере `http://localhost:3000/`.
