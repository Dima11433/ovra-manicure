# OVRA — Авторский маникюр & Кутюрный трикотаж

🌐 **Онлайн демо (GitHub Pages)**: [https://dima11433.github.io/ovra-manicure/](https://dima11433.github.io/ovra-manicure/)

Высококлассный интерактивный single-file лендинг для лейбла авторского маникюра и кутюрного трикотажа OVRA.

---

## 🎨 Архитектура и дизайн
- **3 контрастных фона по секциям**:
  - **Секция 1 (Главный экран)**: Белый фарфор (`#FFFFFF`) с акцентом на силуэт модели, кутюрный маникюр и нежные кустовые розы.
  - **Секция 2 (Коллаж)**: Глубокий красный как кровь (`#3D0005` → `#8A0303`) с контурной типографикой «МАНИКЮР» и композицией с лаком.
  - **Секция 3 (Галерея образов)**: Черный обсидиан (`#09070B` → `#050406`) с цикличным показом коллекций ногтевого дизайна.
- **Интерактивные 3D-эффекты**:
  - Парящие в реальном времени 3D-лепестки роз на Vanilla WebGL с реакцией на движение мыши и плавный скролл.
  - Эффект 3D-наклона карточек при наведении (`perspective(800px)`).
- **Плавная анимация**:
  - Трафаретные прорези букв кириллицы с CSS-масками (`linear-gradient` masks).
  - Эффект реечного проявления изображений (strip reveal).
  - Плавный скролл с инерцией (momentum scrolling).
- **Чистый код**:
  - Никаких внешних UI-библиотек или фреймворков (чистый HTML5, CSS3, ES6 JavaScript, WebGL).
  - Полная адаптивность (десктоп 1440×956 и мобильные устройства).

---

## 🚀 Запуск локально
Открыть `index.html` в любом современном браузере или запустить локальный сервер:
```bash
python -m http.server 3000
```
Затем перейти в браузере по адресу `http://localhost:3000/`.
